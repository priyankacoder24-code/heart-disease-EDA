# Heart Disease EDA

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a Heart Disease dataset using Python.

## Objectives

- Understand the structure of the dataset
- Analyze patient-related features
- Identify missing and duplicate values
- Study distributions of numerical and categorical variables
- Analyze relationships between features
- Identify potential outliers
- Understand correlations between variables
- Generate meaningful visual insights

## EDA Process

1. Data Loading
2. Data Inspection
3. Data Cleaning
4. Missing Value Analysis
5. Duplicate Analysis
6. Statistical Analysis
7. Univariate Analysis
8. Bivariate Analysis
9. Correlation Analysis
10. Outlier Analysis
11. Data Visualization
12. Key Insights

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
